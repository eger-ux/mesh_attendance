# mesh_attendance

`mesh_attendance` — Python-скрипт для расчёта посещаемости на основе данных электронного дневника МЭШ.

Программа получает данные через API, сопоставляет расписание с информацией о пропусках и рассчитывает процент посещаемости по каждому предмету за выбранный период.

## Возможности

- Получение данных об учебном профиле через API МЭШ.
- Выбор периода, за который необходимо рассчитать посещаемость.
- Получение расписания и информации о пропущенных занятиях.
- Подсчёт общего количества занятий и посещённых занятий по каждому предмету.
- Расчёт процента посещаемости.

## Используемые технологии

- **Python** — основной язык программирования.
- **Requests** — отправка HTTP-запросов к API.
- **Pandas** — формирование последовательности дат для выбранного периода.
- **Datetime** — работа с датами.

## Требования

Для запуска необходимы:
- установленный Python;
- доступ к интернету;
- действующий токен для обращения к API МЭШ.

## Установка

### 1. Клонирование репозитория

Откройте терминал и выполните:

```bash
git clone https://github.com/eger-ux/mesh_attendance.git
cd mesh_attendance
```

### 2. Создание виртуального окружения

Виртуальное окружение позволяет изолировать зависимости проекта от остальных Python-программ.

```bash
python -m venv .venv
```

Активируйте его в зависимости от операционной системы.

**Windows (PowerShell):**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Windows (Command Prompt):**

```bat
.venv\Scripts\activate.bat
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

Установите необходимые библиотеки:

```bash
python -m pip install requests pandas
```

После установки проект готов к запуску.

## Запуск

В активированном виртуальном окружении выполните:

```bash
python main.py
```

### 1. Ввод токена

Программа попросит ввести токен для обращения к API. При вводе необходимо использовать действительный токен, полученный законным способом.

```text
Введите токен учащегося.
[Далее программа выводит инструкцию по получению токена и ожидает ввод]
```

В примерах документации не используются реальные токены или данные пользователей.

### 2. Выбор периода

После ввода токена программа предложит указать период расчёта посещаемости.

Можно ввести `Показать все`, чтобы запросить данные за весь предусмотренный программой период, либо указать начальную и конечную даты в формате `ГГГГ-ММ-ДД:ГГГГ-ММ-ДД`.

Пример ввода:

```text
2025-09-01:2025-12-31
```

Это выдуманный пример периода, используемый только для демонстрации формата ввода.

### 3. Получение результатов

После обработки данных программа выводит дни с пропусками, а затем статистику посещаемости по предметам.
